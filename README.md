## Idee

UniW☺W ist eine WebApp, in der Studenten ihre Noten in einzelnen Modulen eintragen, verwalten und einsehen können.
Außerdem werden zu den Modulen Foren angeboten, in denen sich ausgetauscht
werden und die Module bewertet werden können.
